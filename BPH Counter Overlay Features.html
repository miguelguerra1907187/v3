BPH Counter Overlay — Billing Productivity Toolkit

A lightweight on-screen toolkit that helps billers track their pace in real time, spot slow bills early, and enter reference numbers faster and with fewer errors.

Why The challenge this toolkit solves
Billers work against an hourly goal of 32 bills, with reduced goals during break hours. The day-to-day work, however, offers no live view of that goal, and several routine steps are repetitive and done by hand. Small delays add up over a 9-hour shift and usually become visible only when the shift is over.
Pace
No real-time view of the goal
Without a live counter, a biller has to estimate how many bills were done this hour. A slow hour is usually noticed too late to recover it.
Time
Bills that silently take too long
Trouble bills, missing data or a slow screen can keep a biller on one bill for many minutes without realizing how much time has passed.
Data entry
Repetitive copy & paste
One bill can carry many PO or reference numbers. Copying and pasting them one at a time is slow, and it is easy to skip one or enter the same number twice.
Conversions
Manual kg → lbs math
Weights that arrive in kilograms must be entered in pounds, which means opening a calculator every time and the risk of a rounding mistake.
The solution: one small PowerShell script, started with a single double-click, that sits quietly in the corner of the screen and handles all four points: a live bill counter, a per-bill timer, a PO/BOL paste queue and a kg → lbs converter. It does not change the TMS, needs no installation, and works within the current IT restrictions.

Module 1 Live bill counter, buffer & shift report
Counter How the counter works
01
Runs in the background
A small transparent overlay sits in the top-right corner of the screen. It never blocks work and requires no window switching.
02
Counts bills in real time
Every time a bill is processed, the employee presses Alt + S. The counter goes up instantly on screen.
03
Tracks against hourly goal
Each hour has a target. The color of the overlay tells the employee at a glance whether they are on track or falling behind.
04
Generates a shift report
At any point, pressing F11 shows a complete summary: average rate, total bills, buffer, best hour, and breakdown. After viewing, press F11 again or click the report to close it — the overlay resets to zero and keeps running for the next shift.
05
Remembers your progress
If the app is closed and reopened during the same day, all counts and the accumulated buffer are fully restored.
06
Handles shift exceptions
Break hours (4pm, 6pm) have a reduced goal of 24. The 7pm lunch hour is completely excluded — it neither adds nor removes from the score.
07
Smart overtime detection
Hours worked outside the official shift are tracked as OT. If you open the tool early but don't register any bills, that hour is silently discarded. If you do work, it counts fully — affecting AVG, buffer, and appearing tagged in the report.
08
Auto-reset at 4am
If the tool is left open overnight — PC in sleep mode, forgot to press F11 — the counter resets automatically at 4am, so the next shift always starts clean with no leftover data.
Shift time How the 9-hour shift is counted
Total calendar time: 9 hours (2pm to 11pm)
Effective productive time: 7.5 hours — the two break hours (4pm and 6pm) each contribute only 45 active minutes instead of 60, removing 2 × 15 = 30 minutes from the total.
The 7pm lunch hour contributes 0 minutes — anything done there is not counted.

Theoretical max at 32/hr → 7.5 × 32 = 240 bills  |  At 35/hr → 7.5 × 35 = 262 bills

Section 3B Overtime hours — outside the official shift
Any hour worked before 2pm or after 11pm is treated as overtime. The tool detects it automatically — no setup required. If you open the program early and register nothing, that hour is discarded silently. The report marks it with OT so you can distinguish it from your regular shift.

Module 3 PO / BOL paste queue — paste a whole list, one number at a time
When a bill carries several PO or reference numbers, the biller copies the whole list once. After that, every Ctrl + V in the TMS pastes the next number in order. There is no need to go back and forth between the document and the TMS for each number.
01
Copy the list
Copy the numbers from the document (for example with a screen text capture). Commas, slashes, spaces or line breaks between them are all fine.
02
Load it
Press Ctrl + Right Shift. A small box opens; paste the list with Ctrl+V and the box closes by itself. The list is ready.
03
Paste in order
In the TMS, each Ctrl + V pastes the next number. A small panel shows what was just pasted and what comes next.
04
Done
After the last number, the queue empties itself and a notification confirms that all numbers were pasted.
Example
Copied text → queue
Copied: 4500123, 4500456 / 4500789
4500456 4500999
Queue: 4500123 → 4500456 → 4500789 → 4500999
1 duplicate removed (4500456 appeared twice)
Visual check
Always know what was pasted
After every paste, a small panel confirms the number that was pasted and the one that is loaded next. If it does not match the screen, the biller notices immediately instead of at the end.
PASTED: 4500456
NEXT 3/4 : 4500789
Duplicates
Repeated numbers are removed automatically
If the same number appears more than once in the copied text, it is kept only the first time (upper or lower case does not matter). The notification says how many repeats were removed.
Extra keys
Jump fields and start over
The ` key (above Tab) sends 7 Tab presses to jump to the next block of fields. Left Ctrl + Space clears the queue and the clipboard at any time.

Safeguards Built-in protections against errors
Alt + S — 10-second lock
Prevents duplicate bill counts
Every time Alt + S is pressed, the tool records a timestamp. If the same key fires again within 10 seconds — due to a system lag, a processing error, or an accidental double-press — the second trigger is silently ignored. The counter only goes up once per valid action.
Press Alt+S → count: 24 → timestamp saved
Error retry within 10s → ignored ✓
Press Alt+S after 10s → count: 25 → OK
F11 — Report & reset flow
View report, then reset — overlay always keeps running
Pressing F11 shows a confirmation dialog. Confirming opens the report while the overlay continues running behind it. The report stays visible as long as you need. Closing it — by clicking anywhere on it or pressing F11 again — resets the counter, buffer, and log to zero. The overlay is immediately ready for the next shift.
F11 pressed → confirmation dialog
Yes → report shown, overlay keeps running
F11 or click on report → reset to 0, ready for next shift
No in dialog → cancelled, overlay unchanged
4am auto-reset
Overnight protection — counter resets at 4am
If the program is left open overnight — PC in sleep mode, forgot to press F11 — the counter and all history reset automatically at 4am. The next shift always starts with a clean slate. If you worked OT until 3am, press F11 before 4am to capture the full report before the reset fires.
Forgot F11, PC in sleep → program still open
4:00am arrives → counter resets to 0
Next shift opens clean → no leftover data ✓
OT zero-count discard
Opened the tool early but didn't work — zero penalty
If you open the overlay before your shift starts and don't press Alt+S at all, the pre-shift hour is silently discarded when the next hour begins. No penalty, no entry in the report, no impact on the buffer. The same applies to any post-shift hour where you registered nothing.
Open at 1:55pm, count = 0
2pm arrives → 1pm hour discarded ✓
Shift starts clean at 2pm → no impact ✓
Paste queue checks
Order, duplicates and confirmation
Numbers are always pasted in the order they were copied, duplicates are removed before pasting starts, and the on-screen panel confirms every paste. A short pause after each paste gives the TMS time to receive the number before the next one is loaded, so no number is skipped on a slow screen.
One copy at a time
Cannot run twice by mistake
If the launcher is double-clicked again while the toolkit is already open, the second copy closes itself, so bills are never counted twice. If the paste queue ever runs into an unexpected problem, it stops and shows a notification, while the counter keeps running.
Value What the team and the company gain
Self-management during the shift
Each biller sees pace and buffer at all times and can correct a slow hour while there is still time to recover it.
Slow bills surface early
The bill timer makes long bills visible within minutes, so they can be saved or escalated instead of quietly consuming the hour.
Fewer data-entry errors
The paste queue keeps numbers in order, removes duplicates and confirms every paste, reducing skipped or repeated references.
Consistent weight conversions
Every kg → lbs conversion uses the same factor and the same rounding rule, without a calculator.
Objective end-of-shift summary
Average per hour, total bills, buffer, best hour and an hour-by-hour breakdown, with breaks, lunch and overtime handled automatically.
Zero cost, zero installation
Built only with tools already available on company PCs (Windows PowerShell). Nothing to buy, install or maintain on a server.
Security Local only — no data leaves the computer
The toolkit has no network code of any kind: no web requests, no API calls, no cloud sync, no telemetry. The counter only stores numbers (bill counts and minutes) on the employee's own PC. The paste queue works exactly like the employee's own copy and paste: the numbers the biller copies are kept in memory only and placed on the Windows clipboard one at a time. Nothing is written to disk or sent anywhere, and the list is discarded when it is finished, when it is cleared, or when the toolkit is closed.
No network activity
Zero outbound or inbound connections
The script contains no networking commands at all. It cannot send data out or pull anything in, even accidentally. It only uses standard Windows functions to read a few shortcut keys and to draw its own small windows.
What is stored
Only bill counts, on the employee's own PC
The counter saves a bill count, the buffer and minutes per hour in the employee's own Windows profile (HKCU\Software\ContadorOverlay) so progress survives a restart. No PO numbers, BOL numbers, customer names, addresses or other TMS content are ever saved.
Not a keylogger
Listens only to its own shortcut keys
The toolkit only checks whether its specific shortcuts are pressed (Alt+S, F11, F12, Ctrl+V, Ctrl+Right Shift, Left Ctrl+Space and the ` key). It does not record, store or send what the employee types.
No installs
One script, no footprint left behind
Nothing is installed, no services or scheduled tasks are created, and nothing runs once the toolkit is closed. A temporary file in %TEMP% only prevents two copies from running at once.
